使用教程

从收到短信到完成取件

按设备选择合适的接入方式，日常也可以手动粘贴短信或识别照片。

1添加到 iPhone 主屏幕

  1. 使用 Safari 打开取件助手并登录。
  2. 点击浏览器底部的“分享”按钮。
  3. 向下找到“添加到主屏幕”。
  4. 确认名称后点击“添加”。

从主屏幕图标打开后界面更像 App，并可使用系统通知。

2自动接收取件短信

  1. 进入“我的 → API 连接”，复制专属 URL。
  2. 在快捷指令中创建“收到信息”自动化。
  3. 把短信正文作为 txt，发件人作为 phone。
  4. 使用 POST JSON 请求专属 URL。

专属连接包含个人密钥，不要公开分享。详细字段示例仍可在“API 连接”中查看。

3手动添加与照片识别

  • 手动录入粘贴完整取件短信，系统会自动识别并入库。
  • 照片识别可从相册选择最多 5 张，也可以直接拍照。
  • 分享取件码生成 24 小时有效链接给代取人。

4取件和记录

  • 取到包裹后点击右侧圆形按钮，成功反馈后从首页移除。
  • 同一驿站可以使用“全部取出”。
  • 误操作可在“记录”页面恢复为待取。

5通知设置

先从主屏幕图标打开，再进入“我的 → 消息订阅”，点击“测试并允许通知”。只有真实服务器推送成功，才表示订阅链路可用。
